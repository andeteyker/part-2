## Wie Tool-Seiten entstehen

Die 25 URLs liegen nicht als 25 fast identische `page.tsx`-Dateien im Repository. Stattdessen gibt es eine zentrale dynamische Route:

```text
app/tools/[slug]/page.tsx
```

Sie liest die jeweilige Tool-Definition aus der Registry und erzeugt daraus automatisch die komplette Seite. Dadurch können neue Tools mit deutlich weniger dupliziertem Code ergänzt werden.
